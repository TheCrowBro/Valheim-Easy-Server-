Hosting several games at once

The app will run servers for eleven games, several at the same time. On this Mac: Valheim, Minecraft, Vintage Story, Terraria, Project Zomboid and Necesse. Ready for your PC: Enshrouded, Core Keeper, Palworld, Satisfactory and Windrose. The table below shows what you chose; the sections after it show the options as they were offered.

Where the games live in the panel

Today the sidebar holds Valheim's pages: Home, Worlds, Players, Stats, Settings and Log. With several games, each game needs those pages, and some things (Discord, sleep, updates) belong to the whole app. Three ways to arrange that:

A. Games in the sidebar, plus an Overview

Recommended

The sidebar lists your games, each with a live dot and how many people are playing. Overview shows every game at once with Start and Stop. Click a game to get its familiar pages as tabs along the top. App-wide settings sit at the bottom of the sidebar.

Your version: Active and Inactive, with stars

Chosen

Star the games your group is playing these days. Starred games, and any game that's running, sit under Active; the rest fold away under Inactive. Both lists open and close. The Overview puts starred games first, and only starred games get a Discord command. Try it: click a star, or the arrows.

2

Adding a game and turning it on

Add a game opens a list of the games the app knows. Each says plainly whether it runs on this computer, how big the download is, how much memory it needs and what your friends need. Games that can't run here are shown but greyed out, so you know they exist.

Picking one downloads its server, then asks for a server name, a password and a world (start a new one, or bring one from your own game). Anything the game needs behind the scenes, like Java for Minecraft or .NET for Vintage Story, the app fetches itself.

After that each game has its own Start and Stop, and runs alongside the others. You can also remove a game; its worlds are kept as a backup.

The same game twice?

You picked several games at once. Should that also allow two servers of the same game at once, say a plain Valheim world and a modded one side by side?

OptionWhat it means
One server per game RecommendedEach game can have many worlds and you switch between them, but one world per game runs at a time. Simpler to use, and each game's mods stay with its worlds as they do now. I'll build it so adding “a second Valheim” later is a small change.
Any number per game“Add a game” can add Valheim again as a separate server with its own name, port and worlds. More flexible, but the sidebar fills up with look-alike entries, and each copy is a separate download (Valheim's mods live in its server folder).
4

Running several at once

Ports are picked for you. Every game gets its own ports with no overlap, and they're shown on its page in case you ever set up your router by hand.

A memory check before starting. Before a game starts, the app checks it fits beside what's already running. If it doesn't, you get a plain warning instead of a slow, stuttering computer:

Not enough free memory for Vintage Story

Vintage Story needs about 2 GB, and this computer has 1.2 GB free with Valheim and Minecraft running. It may run slowly for everyone.

Stop Minecraft and startStart anywayCancel

Each game's Home page keeps its own CPU and memory charts. The top bar sums things up: “2 games online · 3 playing”.

5

Discord and waking the computer

One Discord channel for everything. Each post names the game, uses its colour, and gives that game's way to join: a join code for Valheim, an address for Minecraft and Vintage Story.

The JetKVM bot gets a /start command that asks which game. It wakes the computer if it's asleep, then starts that game. Your friends' habit of typing /valheim keeps working.

The daily “most deaths” post and the records stay per game.

6

Sleep

The computer goes to sleep only when nobody is playing any game for your chosen time, and nothing is downloading or backing up. Servers left running are started again when it wakes, as Valheim is today.

One optional extra: stop a game when it's been empty for a while (say 2 hours), so a forgotten Minecraft server isn't keeping memory busy all week. Off unless you turn it on.

7

How friends outside your home get in

Valheim's join code works through its own relay, so you've never had to touch your router. Minecraft and Vintage Story have nothing like that: by default, friends outside your home can only connect if the router lets them through. Three ways to handle it, and the app can offer more than one:

WayHow it worksCatch
App opens the ports Recommended firstThe app asks your router to open each game's ports (a standard called UPnP), then checks from outside that friends can actually reach it.Some routers have it switched off, and some internet providers share one address between homes, which stops it working.
Free tunnel BackupA service such as playit.gg gives each game a fixed address that always works, whatever the router. Nothing for friends to install.A one-time free sign-up. Play goes through their servers, which adds a little lag.
By handThe app shows exactly which ports to open, with steps for common routers.Fiddly, and needs the router's admin password.

I'll check Enshrouded and the other shortlisted games for this as the research comes in.
