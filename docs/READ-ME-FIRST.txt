VALHEIM EASY SERVER
===================

Run your own Valheim server on this computer, with a simple control panel
right here on it. Friends who help look after the server use the same
panel through an IP KVM or remote desktop.


SETTING UP (once, on the server computer)
-----------------------------------------
1. Make a folder for the server, for example   C:\Valheim Server
   and put ValheimEasyServer.exe in it. Everything the server needs
   (server files, worlds, backups, logs) is kept in that folder.

2. Double-click ValheimEasyServer.exe.
   If Windows says "Windows protected your PC", click "More info",
   then "Run anyway". (The app isn't signed by a software company.)

3. The control panel opens in its own window. Click "Install the server"
   and wait a few minutes. It downloads the free Valheim dedicated server
   from Steam (about 1 GB). You don't need to own Valheim on this computer.

4. Already have a world? Open "Worlds" and drop it on "Add a world"
   (see ADDING A WORLD below). Otherwise the server makes a new one.

5. Click "Start server". When it says "Online", friends can join with the
   join code and password shown under "How friends join".

6. Finish the checklist under "Setup on this computer" on the Home page:
   - Allow it through Windows Firewall (click Yes when Windows asks)
   - Turn on hibernation
   - Turn on Wake-on-LAN (so your IP KVM can wake the computer)
   - Start this app with Windows

Closing the window doesn't stop anything: the app stays next to the clock
(the shield icon). Click the icon to open the control panel again. Right-click
it for Start, Stop, Hibernate and Close.


NEW TO THE CONTROL PANEL?
-------------------------
Click "Tutorial" on the Home page, right next to "Start server". In six
short steps it shows how to set a world's difficulty and mods, start the
server, join it from Valheim, stop it, switch worlds and let the computer
rest.


THE JOIN CODE IN DISCORD
------------------------
The join code changes each time the server starts. The app can post it in
a Discord channel for you: in Settings, under Discord, turn on "Post the
join code in Discord" and paste the channel's webhook link. To get it:
  1. In Discord, click the gear next to the channel's name (Edit Channel).
  2. Open Integrations and click Create Webhook (or Webhooks, then New
     Webhook).
  3. Click the new webhook, name it (for example Valheim) and click
     Copy Webhook URL.
  4. Paste it in Settings, click "Send a test", look in the channel and
     save.
You can also have it post the password (hidden as a spoiler: only for a
channel that's just for your friends) and say when the server stops.


MODS
----
Each world's card on the Worlds page has switches for two mods:
  - Advanced Portals by RandyKnapp: portals that let metal through.
  - Seasonality by RustyMods: winter, spring, summer and fall.
The app downloads a world's mods the next time the server starts it.

Everyone who plays that world needs the mod in their own game too:
  1. Install a free mod manager: r2modman or Gale (from thunderstore.io).
  2. Choose Valheim, search for the mod ("Advanced Portals" or
     "Seasonality") and install it ("Download" in r2modman). Anything
     else it needs, such as BepInEx, comes with it.
  3. Start Valheim from the mod manager ("Start modded" in r2modman),
     then join as usual.
If joining fails because the versions don't match, update the mod in the
mod manager. On the Home page, "Which mod do I need?" shows these steps
with the mod's download page.
Xbox, PlayStation, Switch and Game Pass players can't use mods.


ADDING A WORLD
--------------
1. On the PC where the world was played, press Windows + R, paste this and
   press Enter:
       %userprofile%\AppData\LocalLow\IronGate\Valheim\worlds_local
   Each world is a folder there (older worlds are two files, Name.fwl and
   Name.db).

2. Bring it to the server computer: on a USB stick, or zip it and send it
   through a chat or cloud drive, then download it there.

3. In the control panel, open "Worlds" and drop the folder, the two files
   or the zip onto "Add a world" (or click "Choose a world folder").
   The app puts it in the right place by itself. It only asks if the
   server already has a world with the same name, and it keeps a backup
   of anything it replaces.


TO PLAY
-------
Open Valheim, go to Join Game and enter the join code (or the address) and
the password from the control panel.


TAKING A COPY OF A WORLD
------------------------
On the Worlds page, click "Download" on the world's card. A Save window
asks where to put the zip: through an IP KVM the file is saved on the
server computer, so pick a cloud-drive folder (such as OneDrive) or a USB
stick. A note inside the zip explains how to play the world on your own PC.


WAKING THE COMPUTER UP
----------------------
After "Hibernate" (or "Sleep"), wake the computer with Wake-on-LAN from
your IP KVM, or press its power button. If the server was running before,
it starts again by itself.

The address the KVM needs (the MAC address) is in Settings, under
"Resting and waking up". The computer must be connected by a network
cable. If Wake-on-LAN doesn't wake it from hibernation, choose "Sleep"
there instead.
